# **App Name**: AI-Refactor Pro

## Core Features:

- Guided Workflow: Multi-step form guiding users through CV upload, profile, job details, and generation.
- CV Parsing: Parses text from uploaded PDF CVs, handling file uploads and extractions
- PDF Export: Generates downloadable PDFs, allowing export of both CV and cover letter content.
- AI-Powered CV Tailoring: AI-driven formatting and improvements that tool the resume into sections appropriate to the uploaded job description.
- AI Cover Letter Generation: AI tool generating a cover letter based on user profile and job description, offering personalized content.
- Session Persistence: Saves user progress to localStorage for session persistence.
- CV Upload: Drag-and-drop CV upload area.

## Style Guidelines:

- Primary color: Deep Indigo (#4F46E5) for a professional, trustworthy feel.
- Background color: Very light Indigo (#F5F3FF) providing a subtle backdrop that's easy on the eyes.
- Accent color: Soft Lavender (#A78BFA) for highlights and interactive elements, creating visual interest without overwhelming.
- Body: 'Inter', a grotesque sans-serif font that ensures clear and modern text for the body.
- Headline: 'Space Grotesk', a proportional sans-serif font for headlines. Pair with 'Inter' for body text.
- Lucide-react icons, known for their clean and modern aesthetic.
- Centered layout with a max-width container, ensuring a clean and spacious design.
