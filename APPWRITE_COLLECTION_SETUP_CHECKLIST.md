## ✅ Issue 2: Licenses Collection Query Error

**Error:**
```
Invalid query: Attribute not found in schema: createdAt
```

**Root Cause:**
The `licenses` collection is missing the `createdAt` attribute in Appwrite Console.

**Fix Required in Appwrite Console:**

### Step 1: Go to Licenses Collection
1. Open Appwrite Console
2. Navigate to your database
3. Click on `licenses` collection
4. Go to "Attributes" tab

### Step 2: Add Missing Attribute
Click "Create Attribute" and add:

| Field Name  | Type     | Size | Required | Default | Array |
| ----------- | -------- | ---- | -------- | ------- | ----- |
| `createdAt` | DateTime | -    | Yes      | -       | No    |

**Important Notes:**
- This is a **manual DateTime field** (not auto-generated)
- The code will set this value when admins create licenses
- This is different from `$createdAt` which Appwrite auto-generates
- Used for tracking when the license was created by admin

### Step 3: Verify Index
Make sure you have an index on `createdAt`:
- Index Type: Key
- Attribute: `createdAt`
- Order: DESC (for sorting newest first)

## 📞 Common Issues

### "Attribute not found in schema"
- You forgot to create an attribute in Appwrite Console
- Check the collection and add the missing attribute

### "Invalid document structure"
- Field type mismatch (e.g., String instead of Email)
- Required field is missing
- Value doesn't match the field type

### "Collection not found"
- Collection ID mismatch in `.env.local`
- Collection doesn't exist
- Wrong database ID
