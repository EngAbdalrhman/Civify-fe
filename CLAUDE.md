# Civify frontend

This worktree is based on Production. Read `../Knowledge/README.md` and
`../Knowledge/frontend-pagespeed.md` before repeating performance investigation.
Keep the original `../Civify-fe/` checkout unchanged.

`src/lib/llms.ts` is the agent documentation source; its tool directory imports
`public/.well-known/mcp/server-card.json`, generated by the MCP repository's
export:server-card script after building. Do not add public/llms.txt: it shadows
the route. The authenticated API-key page is /en/app/api-keys.

Use a supported Node version (the verified build used bundled Node 24). Run the
production build and `node --test test/pdf-workflow.test.cjs` after renderer or
watermark changes. Account policy is authoritative; never honor an untrusted body
that tries to disable watermarks. Backend policy and JSON-tailoring additions must
deploy before the MCP gateway. Record remaining live verification in Knowledge.

Browser account linking is /[locale]/mcp/connect. It reuses login/signup/2FA/SSO and
calls authenticated backend /mcp/account-link routes. Never collect an API key on
the consent page. auth-return.ts validates same-site login destinations and the
fixed gateway callback; its tests are test/auth-return.test.cjs. See
../Knowledge/2026-09-25-account-linking.md for coordinated deployment and limits.
